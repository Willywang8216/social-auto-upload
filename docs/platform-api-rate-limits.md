## Implementation policy

- Published size units with ambiguous MB/GB definitions use conservative decimal bytes in SAU. Policy values are not claims of universal API maxima.
- Prepare exact local media, retain immutable originals, compress to measured byte budgets, split complete content when necessary, validate final outputs after watermarking and verify hashes again before schedule/upload.
- Allocate complete ordered posts through canonical destination pacing: production defaults **three/day with a 30-minute minimum gap**. Requested recovery caps can tighten, never raise/disable the current cap. Count aliases, confirmed deliveries, existing bookings, and unresolved/in-flight work.
- Persist provider selection, separate finite native/backup budgets, stable retry idempotency, and `Retry-After`/reset deadlines; release concurrency while waiting. Accepted/uncertain submissions retain their provider receipts for reconciliation, not blind backup.
- Terminal failed/blocked/review outcome and its deduplicated alert event commit in one transaction. The outbox independently retries notifications after restart; it never reruns publication or floods all historical failures.
- AI transcript preprocessing uses deduplicated adjacent lines, bounded UTF-8 chunks, bounded summarization passes and per-source summary reuse. These are application budgets, not provider TPM entitlements; configured model/account quotas and rate responses still apply.
